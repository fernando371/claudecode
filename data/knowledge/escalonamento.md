# Quando transferir para um atendente humano

| Situação                                                     | Prioridade                         |
| ------------------------------------------------------------ | ---------------------------------- |
| Reação adversa                                               | Alta                               |
| Superdosagem                                                 | Alta                               |
| Produto avariado, alterado ou suspeita de falsificação       | Alta                               |
| Gravidez, amamentação, criança, doença, medicamento, alergia | Alta                               |
| Pedido extraviado                                            | Alta                               |
| Pedido atrasado                                              | Normal                             |
| Integração fora do ar                                        | Normal                             |
| Sem fonte oficial aprovada                                   | Normal                             |
| Cliente pediu atendente                                      | Normal                             |
| Tentativa de acesso a pedido de outra pessoa                 | Normal (com registro de auditoria) |
| Modo de emergência ativo                                     | Normal                             |

## O que vai junto na transferência

Resumo da conversa **já mascarado**, intenção detectada, regras acionadas e
o motivo do escalonamento. Nunca vai CPF, dado financeiro nem texto clínico completo.
